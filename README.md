# 🚀 Daily Coding Challenges

Este repositorio está dedicado a la practica de **Lógica de programación**. El objetivo es resolver un reto tecnico para mejorar la capacidad de resolución de problemas.

Aunque los ejercicios son universales y aplicables a cualquier lenguaje, mis soluciones están enfocadas principalmente en:
* **C#**
* **Python**

## 📂 Estructura del Repositorio

El proyecto está organizado por carpetas para mantener la limpieza entre lenguajes:

```
.
├── 🐍 Python/           # Soluciones en Python
├── 🎯 CSharp/           # Soluciones en C# (.NET)
└── README.md            # Guía del repositorio
```
